# data-analysis adapter

このファイルはClaude Code向けの薄いadapterです。structured data、query結果、KPI、metric diagnostics、forecast、causal analysis、reportを扱う前に、[`.agents/skills/data-analysis/SKILL.md`](../../../.agents/skills/data-analysis/SKILL.md) を読み、その内容を唯一の手順正本として適用します。

Claude Code固有のtool名や操作は、正本のquality gate、sample / production境界、evidence区分、write / publish権限を変更しません。
