## 2. ユーザー価値

- 対象ユーザー: 保存済み WordPack から次に復習するまとまりを探す利用者
- 利用文脈: 保存語が増え、更新状況・例文生成・学習記録・カテゴリ別に絞りたいとき
- ユーザー目的: 目的に合う棚を選び、対象 WordPack を確認してプレビューを開始する
- 支援するタスク: 棚の把握、棚または WordPack の検索、対象一覧への移動、プレビュー
- 支援する理解・判断・行動:
  - 理解: Shelves は内容を変更せず、自動分類した復習対象を示す
  - 判断: 棚名、説明、件数、選択状態、右レールで現在の対象を比較する
  - 行動: 「この棚を表示」から一覧へ移動し、WordPack をプレビューする
  - 回復: 検索解除、再読み込み、再更新、全件再読み込みを状態に応じて選ぶ
- この UI がなければ困る点: 保存語を一件ずつ開かなければ、復習目的に合う集合を判断できない
- 削った情報・操作: `entries`、`shown`、`guest_public` などの内部・英語コピーと、結果が伝わらない「開く」
- 検証仮説・成功指標: 棚選択後に対象見出しへフォーカスが移り、表示件数が通知され、検索時にカード・一覧・右レールが同じ対象と件数を示す

## 3. 初見理解

### 前提

- 対象ユーザー: WordPack の保存経験はあるが Shelves は初めて
- 利用文脈: 保存語をまとめて復習したい
- 事前知識として許可するもの: 「棚」が複数項目をまとめる比喩であること
- 事前知識として許可しないもの: 分類ルール、内部フィールド、一覧が画面下部にあること

### 3秒確認

- 何の画面か: 保存済み WordPack を条件別に自動分類する画面
- 今どこか: 左ナビゲーションとページ見出しの Shelves
- 最初に何をすべきか: 目的に近い棚の「この棚を表示」を押す
- 主操作: 棚の表示、検索、WordPack のプレビュー
- 不明点: 分類が編集操作かどうかは導入文の「内容は変更しません」で解消する

### タスク試行

| ステップ | ユーザーの予測 | 見つけた UI | 実行する操作 | 結果理解 | 迷い |
|---|---|---|---|---|---|
| 1 | 未生成語をまとめて見たい | 「未生成」カードと1件の件数 | 「この棚を表示」 | 一覧見出しへ移動し1件が表示される | なし |
| 2 | 特定語を探したい | 棚と WordPack の検索欄 | 語を入力 | 一致カード・件数・一覧だけに絞られる | なし |
| 3 | 検索を戻したい | 単一の該当なし状態 | 「検索を解除」 | 全棚へ戻り検索欄へフォーカスする | なし |

- 判定: Pass
- P0 / P1 / P2: 未対応なし
- 制約: 実ユーザー調査ではなく、ガバナンスに基づく実装者シミュレーション

## 5. アクセシビリティ確認

- キーボード: 棚ボタン、検索、検索解除、プレビューを Tab / Enter で操作可能
- フォーカス: 棚選択後は一覧見出しへ移動し、可視アウトラインを表示
- 名前・ラベル: 棚名を含む「一覧を表示 / へ移動」、見出し語を含む「プレビュー」
- 見出し・構造: ページ h2、セクション h3、カード h4、棚・棚内 WordPack 一覧 `ul`
- コントラスト: 既存テーマを保持し、選択・フォーカスは色だけでなくラベルと輪郭でも表現
- ターゲットサイズ: 既存 Button コンポーネントを使用
- エラー・ステータス: loading / success / error / partial を status または alert で通知
- 自動検査: axe（デスクトップ、390px、200%）で重大度 serious 以上の違反なし
- 手動確認: キーボードフォーカス、accessible name、DOM 順、選択表示、右レールのスクロール領域フォーカスを確認

## 6. 視覚階層

- 主操作: 各カード右下の「この棚を表示」。選択中はバッジと「一覧へ移動」
- 情報優先度: 画面目的 → 検索 / 更新 → 棚比較 → 選択棚一覧 → プレビュー
- グルーピング: 棚カード群と選択結果を別 section とし、右レールは集計に限定
- 余白・密度: 既存密度を維持し、選択バッジを件数と同じ要約行へ配置
- 読みやすさ: 件数を日本語化し、内部フィールドを利用者向け表現へ変更
- 狭幅・文字拡大: カードと WordPack 一覧を1列化し、横スクロールを発生させない

## 7. コピー

- 用語: `Smart Shelves` を「自動分類の棚」、`entries / shown` を「件 / 件表示」
- ボタン・リンク: 「開く」を「この棚を表示 / 一覧へ移動」
- エラー文: 原因の断定を避け、影響と接続確認、再試行を同じ状態内に表示
- 空状態: 保存なし、検索結果なし、棚内0件を別の理由と回復方法で表示
- disabled: 更新中はラベルを「更新中」に変更
- トーン: 利用者を責めず、現在表示しているデータ範囲を明示

## 8. 熟練者効率

- 主要反復タスク: 棚の比較、検索、選択棚への再移動、プレビュー
- 手数:

| タスク | 手数 | 改善 |
|---|---:|---|
| 任意棚の一覧へ移動 | 1 | ボタンから対象見出しへ直接移動 |
| 検索開始 | 1 | `Command / Ctrl + K` |
| 検索解除 | 1 | 該当なし / 棚内0件から解除 |

- 再入力・再選択: 更新中 / 更新失敗でも最後の成功一覧と選択を保持
- 近道: 検索ショートカット。自動分類のため一括編集・テンプレートは対象外
- 初心者向け説明の影響: 各セクションに短い1文だけを常設し、反復操作を遮らない
- 判定: Pass

## 9. 満足感・信頼感

- 待機中: 初回と更新を区別し、更新中も現在データを利用可能
- 成功時: 一覧見出し、表示件数、ライブ通知で結果が分かる
- 失敗時: 初回は影響と再読込、更新時は保持データと再更新を明示
- 危険操作: データ変更・削除を行わない。導入文でも内容を変更しないと明示
- データ・権限・個人情報: 保存済み WordPack の既存取得契約だけを使用。公開状態は「ゲスト公開中」と利用者向けに表示
- トーン: 内部エラーで責めず、未確認の原因を断定しない
- 判定: Pass
